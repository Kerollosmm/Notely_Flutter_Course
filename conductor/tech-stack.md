# Tech Stack

## Core Technologies
- **Language**: Dart (^3.8.1)
- **Framework**: Flutter (Material 3 enabled)

## Backend & Cloud Services
- **Firebase Core**: Project initialization and core services.
- **Firebase Auth**: Secure user authentication and management.
- **Cloud Firestore**: Real-time NoSQL database for cloud synchronization.

## State Management
- **flutter_bloc**: Primary state management for business logic and UI states.
- **provider**: Secondary state management for simpler dependency injection or local state.

## Data Persistence
- **sqflite**: Local SQLite database for offline caching and persistent storage.
- **shared_preferences**: Key-value storage for simple settings and local preferences.

## UI & UX Utilities
- **flutter_screenutil**: Ensuring a responsive and adaptive UI across various screen sizes.
- **google_fonts**: Integrated custom typography (Spline Sans, Inter, Open Sans).
- **flutter_quill**: Rich text editing and formatting.
- **fluttertoast**: Quick user feedback notifications.

## External Integrations & Utilities
- **share_plus**: Cross-platform sharing of note content.
- **url_launcher**: Opening links and external applications.
- **connectivity_plus**: Monitoring network state for cloud sync management.
- **uuid**: Generating unique identifiers for local and cloud data.
- **equatable**: Simplifying object comparisons for bloc state updates.
